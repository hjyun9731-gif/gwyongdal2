# 검증 결과

## 실제 명부 파일

실제 업로드 파일 2개를 Phase 1 Import 로직으로 파싱 → 미리보기 → 반영 테스트했습니다.

### 택배회원
- 원본 데이터행: 2,248
- 자동 반영 가능: 2,244
- `needs_review`: 4
  - 원인: 업로드 파일 내부 차량번호 중복
- 필수값 오류: 0

### 개인회원
- 원본 데이터행: 1,608
- 자동 반영 가능: 1,558
- `needs_review`: 7
  - 원인: 업로드 파일 내부 차량번호 중복
- `invalid`: 43
  - 원인: `vehicle_number` 누락 43건

### 합계
- 원본: 3,856행
- 자동 반영 가능: 3,802명
- 차량번호 중복 검토 필요: 11행
- 차량번호 누락 검토 필요: 43행

따라서 원본 3,856행을 무조건 회원으로 넣지 않습니다. 차량번호 중복은 관리자 선택을 거치고, 차량번호 누락은 `invalid`로 분리합니다.

## 실제 API 스모크 테스트

별도 검증 DB에서 다음을 실제 실행했습니다.

1. Alembic 초기 migration 적용
2. 실제 택배/개인 명부 Import
3. 관리자 비밀번호 + TOTP 로그인
4. 관리자 대시보드 조회
5. 실제 명부 회원 1명으로 최초 등록 lookup
6. 4자리 PIN 설정
7. 기사 세션 발급
8. 기사 본인정보(차종/휴대폰/주소) 조회
9. 법정 11개 점검항목 조회
10. 오늘 `전체 양호` 저장
11. 기사 홈에서 오늘 완료 확인
12. 법정 일상점검표 HTML 출력

결과: **SMOKE PASS**

자동 단위테스트: **5 passed**
